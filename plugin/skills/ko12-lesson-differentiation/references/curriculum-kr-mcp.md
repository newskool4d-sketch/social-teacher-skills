# 한국 교육과정 학습맵 MCP — 호출 시퀀스 (차별화)

`ko12-lesson-differentiation` Step 2에서 **학습맵 MCP 도구가 연결된 경우에만** 사용한다.
연결되지 않았다면 이 파일 전체를 건너뛴다 (SKILL.md Step 2에 폴백 있음).
연결됐는데 호출하지 않는 것은 치명적 실패(critical failure)다. 원본 수업을 어떻게
얻었든(업로드·붙여넣기·링크) 마찬가지다 — 수업을 확보한 것이 이 단계를 대신하지 않는다.

**차별화에서 이 조회가 하는 일은 수업 설계와 다르다.** 새 수업을 짓는 것이 아니라,
이미 있는 수업의 성취기준을 확인하고 **수준별 진입점의 근거**를 찾는 것이다:
선수관계는 기초 수준 스캐폴드의 다리가 되고(R3), 세부 주제의 관찰 증거는 형성 확인의
분류 기준이 된다(R5). **심화 연계는 사회과에 해당 사항이 없다** — 학습맵에 사회 관련
전이 데이터가 없으므로(0건 실측), 심화 확장(R7)의 근거는 심화 연계가 아니라 R7 자체의
확장 품질 기준에서 댄다.

## 서버 라우팅 (모든 과목 공통)

두 개의 독립 MCP 서버가 있다. **서로 다른 그래프이며 교차 조회되지 않는다.**

| 학교급 | 서버 | 도구 접두 신호 |
| --- | --- | --- |
| 초등 (1–6학년) | `curriculum-kr-elementary` | 성취기준 코드 `[2xx…]` `[4xx…]` `[6xx…]` — `gradeBand: "1-2" \| "3-4" \| "5-6"` |
| 중·고 (보통교과) | `curriculum-kr-secondary` | 코드 `[9xx…]` (중), `[10xx…]` `[12xx…]` (고) — `schoolLevel: "middle" \| "high"`, `gradeBand: "7-9" \| "10" \| "10-12"` |

**두 서버의 차이 (실측):**
- 초등에는 `get_transitions`가 없다 (중→고 전이는 중등 전용). 초등은 9종, 중등은 11종.
- 초등 `search_standards` 결과의 요약 필드는 `summary`가 아니라 `focus`이지만, **사회과 레코드는
  `focus`가 항상 빈 값이다**(실측 2026-08-29, repo 데이터 기준 — 라이브 MCP 응답에서 재확인) —
  요약 필드에 의존하지 말고 코드·영역명이나 `get_standard`의 `officialText`로 확인한다. 초등
  `get_standard`에는 `subject` 파라미터가 없다.
- ⚠ **초등 성취기준 원문은 조건부로 verbatim이다.** v0.5.0부터 `officialText`는 NCIC 고시
  PDF에서 자동 추출한 공식 원문이며(재구성 값이 아니다), 레코드의 `sourceTextIncluded: false`
  플래그는 이전 버전부터 남아 있는 낡은 메타데이터로 실제 동작과 무관하다. 다만 **약 8%
  항목에 절취 결함**(해설 문단 혼입, 문장이 다음 단원 제목까지 잘림 등)이 있다 — **결함이
  보이는 항목**은 수업안 푸터에 다음을 단다:
  *"초등 성취기준 원문은 NCIC 고시 PDF에서 자동 추출한 것입니다(재구성 아님). 다만 일부
  항목(약 8%)은 절취 과정에서 해설 문단이 섞이거나 문장이 잘렸을 수 있으니, 인용 전 공식
  고시문과 대조해 확인하세요."*
  중등·통합사회는 `sourceLocator`(PDF 쪽·sha256)를 갖춘 verbatim이며 이 조건이 없다.

라우팅 규칙:
- 교사가 말한 **학년**으로 서버를 정한다. 중학교 수업이면 secondary만 호출한다.
- 단, **선수학습 결손 진단** 맥락(중1 대상, "기초가 안 된", "초등 내용부터")이 명시되면
  elementary를 추가 호출해 초등 성취기준을 역추적한다.
- **초→중 브리지는 두 그래프 어디에도 없다.** 초등 결손 추적은 코드 연결이 아니라
  **키워드 병렬 검색**으로 한다: 같은 주제어로 두 서버의 `search_standards`를 각각 호출하고,
  학년군 순서로 모델이 직접 잇는다. 이 연결은 "추정 연계"임을 산출물에 표시한다.
- 중→고 심화 연계는 secondary의 `get_transitions`가 공식 근거(별책) 기반으로 제공한다 —
  추정 아님(과목마다 수록 여부가 다르다; **사회·통합사회1·2는 수록 전이가 0건**이므로
  아래 사회 절 4단계에서 이 호출을 생략한다).
- **통합사회1·2 라우팅**: 코드 `[10통사1-NN-NN]`/`[10통사2-NN-NN]`(실측)은 secondary로
  라우팅하며 `schoolLevel: "high"`로 지정한다(고등학교 공통 과목, `gradeBand: "10"`).
  `search_standards`로 범위를 좁힐 때의 `subject` 값은 `"통합사회1"`/`"통합사회2"`(중학교
  사회는 `"사회"`) — `get_standard`에는 넘기지 않는다(아래 성취기준 확정 절 참조).

## 성취기준 확정 (모든 과목 공통)

원본의 `find_standard_statement` 역할을 3개 도구가 분담한다:

- **코드가 주어진 경우** ("[9사(일사)01-01]", "9사(일사)01-01" 둘 다 수용): `get_standard(code,
  subject?)` 직행. 코드 공유 과목(12스문·12심독 계열 11개 등)은 `subject` 파라미터로 구분해야
  하지만, **사회·통합사회1·2 코드는 이 목록에 없다 — `get_standard`는 코드만으로 유일하게
  정해지므로 `subject`를 넘기지 않는다**(실측 2026-08-29, repo 데이터 기준 — 라이브 MCP 응답에서 재확인).
  코드 형식이 안 맞아 실패하면 → 키워드 검색으로 폴백; 반환된 실제 `code` 값으로 형식을 확인해
  재시도.
- **코드가 없는 경우**: `search_standards(query, schoolLevel?, subject?, domain?, gradeBand?)` —
  요약 목록 반환. `gradeBand`는 `"7-9"`(중) / `"10"`(고 공통) / `"10-12"`(고 선택).
  성취기준 **원문 표현**으로 찾아야 할 때는 `search_standard_text(query, …)`(전문 검색, 매칭 스니펫)를 쓴다.
  가장 적합한 항목을 고르고 `get_standard`로 전체 레코드 + **공식 원문** + 연결 주제를 가져온다.
- **총 검색 시도 3회 상한.** 엉뚱한 학년군·과목 결과는 실패로 계산 — 남은 시도는 다른
  키워드(과목명, 영역명, 소재)로 쓴다. 3회 후에도 없으면 검색 중단, 훈련 지식의 최적
  성취기준으로 진행하고 부분-커버리지 푸터를 수업안에 단다.

확정된 성취기준에서 추출: **`officialText`**(공식 원문 — 수업안 성취기준 콜아웃에 verbatim 인용),
`code`, 그리고 연결된 **주제 ID 목록**(`linkedTopics[].id` — 이후 호출에 필요, 저장).
⚠ `summary` 필드는 기계 생성 요약(`summaryKind: "mechanical-derivative"`)이다 — 인용에 쓰지
않는다. 원문은 `officialText`뿐이다.

## 사회 (Social Studies) — 차별화

초안 작성 **전에** 호출한다. 연결됐는데 호출하지 않으면 치명적 실패다. 모든 호출을 마치고
아래 명시된 것만 추출한 뒤 곧장 Step 3으로 간다 — 학습맵 조회 결과는 채팅에 요약하지 않고,
초안의 성취기준 한 줄 읽어주기(read-back)로만 드러낸다.

**차별화에서 각 결과가 가는 자리** (아래 1–6과 대응):
성취기준 → 수업안 머리 콜아웃 + 학습지 3종의 `eyebrow` / 선수관계 → 3범주 지도의
"선수 학습" + 기초 수준 스캐폴드의 다리(R3 — edge가 없거나 인용할 수 없으면 "추정") /
세부 주제 → 형성 확인의 분류 기준(R5) / 심화 연계 → **호출 생략**(전이 0건 실측, 3범주
지도에 "다음 연계" 줄을 만들지 않는다 — 심화 확장(R7)의 근거는 R7 자체의 확장 품질
기준에서 댄다) / 예상되는 학생 생각 → 수준별 콜아웃(R5).

호출 간 데이터 의존은 성취기준의 **주제 ID**(2–3단계에서 사용) 하나뿐이다. 따라서:
성취기준을 확정한 뒤, 2–3단계 호출을 **하나의 병렬 배치**로 실행한다 (4단계 심화 연계는
사회과에서 호출 자체를 생략한다 — 아래 참조).

**사용 도구:** `search_standards`, `search_standard_text`, `get_standard`, `search_topics`,
`get_topic`, `get_prerequisites`, `get_learning_roadmap`, `get_transitions`(secondary 전용,
사회과는 미호출 — 4단계 참조), `list_clusters`.

1. **성취기준**: 위 *성취기준 확정* 절차대로. `get_standard`가 반환한 **공식 원문**을
   수업안의 성취기준 콜아웃에 그대로 쓴다. 연결 주제 ID들을 저장한다.

2. **선수관계**: `get_prerequisites(topicId, depth: "all")` → 추출: 위상 정렬된 선수 경로
   (`pathOrder[]`)에서 **직전 선수 주제 1개**(그 주제가 속한 성취기준 코드 포함). 학습 목표
   섹션에 사용. 학습맵에 edge가 있는데 명시하지 않는 것은 치명적 실패다.
   ⚠ 응답 필드명은 **`edges`**다(`{topicId, direction, edges: [...]}`). 과학판 문서의 `directEdges`
   표기는 오기다(실측 2026-08-29, repo 데이터 기준 — 라이브 MCP 응답에서 재확인).
   ⚠ **사회과는 공식 근거가 있는 선수 edge가 거의 없다**(secondary 사회 관련 topic 252건
   중 1건 — 실측). 나머지는 `edges: []`로 반환된다. 그 경우 훈련 지식으로 직전 선수 내용을
   쓰되 **"추정"임을 수업안에 표시한다** — 학습맵 근거인 것처럼 쓰지 않는다.
   ⚠ **초등 edge는 있어도 "추정"으로 쓴다.** elementary는 edge가 조밀하지만(사회 topic
   147건 중 98건) 전부 같은 성취기준 **내부**의 하위주제 연결(`basis: "workstream-authored"`,
   자체 저작)이라 교차 성취기준을 잇는 공식 선수 근거가 아니다 — edge 유무와 무관하게
   "추정" 표시를 쓴다.
   중학교 수업 + 결손 진단 맥락이면 elementary 서버에도 키워드 병렬 검색(위 라우팅 규칙).

3. **세부 학습 주제**: 저장한 주제 ID들에 `get_topic(topicId)` → 추출: 관찰 증거(`evidence[]`)와
   평가 문항(`assessmentPrompts[]`), 관점 키(`facetKey` — 예: 자료·맥락 해석과 관점 비교 /
   근거 기반 판단과 사회적 적용). 주제는 성취기준을 관점별로 분해한 **자동 생성 후보 단위**라
   서술이 템플릿형이다 — 그대로 복사하지 말고 **시드로 쓴다**: `facetKey` 관점을 수업 목표
   불릿과 look-for 행의 뼈대로 삼고, `evidence`를 이번 수업의 활동·소재로 구체화한 "구체적
   학생 행동"으로 재진술한다. `assessmentPrompts`는 형성평가·정리 문항(exit ticket) 설계의
   시드. 나머지는 버린다.

4. **심화 연계**: **사회과는 이 호출을 생략한다.** secondary `get_transitions`(전체 175건)에는
   사회·통합사회1·2 관련 전이가 **0건**이다(실측 2026-08-29 — 사회 계열과 걸치는 2건은 모두
   범위 밖인 역사 관련 전이). 호출해도 항상 빈 배열이 반환될 것으로 예상되므로 아예 호출하지
   않는다. "이 내용은 이후 ___로 심화된다" 문장은 만들지 않는다 — 훈련 지식으로 지어내지
   않는다 (수업안 "단원 맥락" 섹션에서 이 문장 자체를 생략).

5. **예상되는 학생 생각**: **학습맵에 이 데이터를 위한 도구가 없다.** 훈련 지식에서 3개를
   작성하되, 각 항목은 반드시 해당 성취기준의 원문 표현과 3단계에서 얻은 세부 주제에
   정합해야 한다. 사회과는 자연과학형 "오개념"보다 **선개념·고정관념** 성격이 크다 — 예:
   "법은 처벌을 위한 것", "지도의 위가 항상 북쪽" 유형. 형식: *학생의 생각* / *지속되는 이유* /
   *교사의 대응*.
   차별화에서는 이것을 **수준별로** 배치한다 — 어느 생각이 어느 수준에서 살아 있을지
   판단해 R5의 수준별 콜아웃에 나눠 쓴다(수준당 2문장 이내).
   (같은 성격의 데이터 소스가 별도 MCP로 연결된 경우 — 도구명에 misconception이 포함 —
   그쪽을 우선 호출하고 훈련 지식은 폴백으로 강등한다.)

6. **커리큘럼 자료**: **한국판에는 특정 출판사 교과서·프로그램 대응 자료 검색이 없다.** 이
   단계는 생략한다. 교과서 출판사별 전개는 학교마다 다르므로, 차별화는 원본 수업과
   성취기준·주제 데이터만으로 설계하고 특정 출판사 교과서의 활동·삽화·지문을 재현하지
   않는다.

**학습맵 미연결 시:** 최선의 지식으로 작성하고 푸터 추가:
*"한국 교육과정 학습맵 미연결 상태에서 생성됨. 성취기준 표현과 예상되는 학생 생각은 일반적 모범 사례 기준."*

→ **학습맵 단계 완료. 곧장 Step 3으로.**
