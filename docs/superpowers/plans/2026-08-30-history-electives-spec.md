## 2. 핵심 설계 결정 (E-1 ~ E-10)

| # | 결정 | 근거 |
|---|---|---|
| E-1 | **같은 플러그인 내 확장** — Step 0 판별을 social \| history 2-way + 범위 밖으로 확대, `references/history.md` ×2 신설 | Step 0→과목 레퍼런스 구조가 원본(upstream)의 다과목 방식. 역사는 사회과 교과군이라 ADR-5(타 교과 동거 폐기)와 무충돌 |
| E-2 | **선택과목은 social.md 고 밴드의 "선택과목 분기" 절로** (신규 파일 아님) — 통합사회 구조 재사용 + 영역별 조정 delta만(경제=통계·모형 해석 / 정치·법과 사회=쟁점·판례·법령 / 사회와 문화=연구 방법 / 지리=공간 자료) | 선택과목 pedagogy는 자료 기반 탐구의 영역 심화 — 파일 분리는 YAGNI |
| E-3 | **history.md는 사료 탐구 아크로 신설**: 시대 질문 → 사료 읽기(출처 확인: 누가·언제·왜) → 교차 검증·맥락화 → 해석 구성(주장-근거-사료) → 정리 문항. 협상 불가: 사실/해석 구분·시대착오 금지·사료 없는 단정 금지·복수 해석 제시(평가 갈리는 인물·사건) | upstream social_studies.md의 C3 sourcing pedagogy가 원재료(history 포함 설계). 사회판과 구조 동형 유지(SKILL.md 참조 계약) |
| E-4 | 3범주(지식·이해/과정·기능/가치·태도) 무수정 이월, 차별화는 **R1~R8 구조 재사용** — 역사판 R6: 같은 사료·같은 질문, 사료 난도 조정 금지(읽기 지원으로 해결) | 전 교과 공통 내용 체계 + v0.1 R6 anti-upstream 결정 계승 |
| E-5 | `shared.subject`/eyebrow: 중 역사 `"역사"`·`"[학년] 역사 · [코드]"`, 고 `"한국사1"/"한국사2"`, 선택과목은 실측 과목명 verbatim (`"정치"`, `"법과 사회"` 등) | v0.1의 통합사회1/2 선례(과목명=subject=eyebrow 정합) |
| E-6 | 파일럿 증분 4종(lesson): 중 역사 1(+differentiation 1) / 한국사1 1 / 선택과목 2(논쟁 밀도 높은 것 1 포함 — 실측 후 확정). 기존 파일럿 7패키지 무변경 유지, CI 루프 확장 | v0.1 파일럿 방법론(ground-truth·byte-verbatim·한컴 실열림) 재적용 |
| E-7 | 루브릭: **P-H 계열 신설**(사료 실재성·출처 확인 요구·사실/해석 구분·시대착오 금지·복수 해석) + P-C Conditional 확장(선택과목). 실채점은 신규 파일럿 전체 + 기존 파일럿 회귀 표본 | "측정 없이 수정 없다" 계승 |
| E-8 | 버전 **0.2.0-preview.1**, 계보 표기 무변경 | SemVer minor(기능 추가, 호환 유지) |
| E-9 | 실측 delta 조사: 기존 클론(`.superpowers/sdd/2026-08-29-social-port/external/`) 재사용, 소실 시 동일 절차 재클론. npx 실행 금지(v0.1 Ruling 1 유지 — elementary MCP 미심사) | 데이터는 중등맵에 이미 수록(보통교과 3,838건). 역사 전이 2건 실측 이력(survey §5) |
| E-10 | **역사 고유 가드레일**: 연도·사건명·인물 서술은 학습맵·실측 우선, 훈련 지식 단독 서술에는 "확인 필요" 표기(사용자 규칙 §9 반영). 근현대사 쟁점은 논쟁 가드레일 + 복수 해석 병기. 검정 역사 교과서 출판사 명명 금지(민감도 최상) | 역사과는 사실 오류·서술 편향 리스크가 사회과보다 높음 |

1. CI 전 게이트(확장 루프 포함) 로컬 재현 + 원격 성공.
2. 신규 파일럿 전부: officialText byte 일치·분 합계·3범주·가드레일(역사: 복수 해석·확인 필요 관례 포함).

4. 기존 범위 무회귀: v0.1 파일럿 7패키지 재렌더·재검사 통과.

6. push는 파일 목록 제시 → 사용자 승인 후.
