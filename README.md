# social-teacher-skills

**한국 2022 개정 교육과정 기반 사회·역사 수업 설계 Claude 스킬 (v0.3.0-preview.1)**

Anthropic의 [k12-teacher-skills](https://github.com/anthropics/k12-teacher-skills)를 한국
초·중등 체제로 이식한 [science-teacher-skills](https://github.com/raphysicst-create/science-teacher-skills)
(과학 전용, v0.3.0-preview.1)를 **사회과로 전면 대체**한 저장소입니다. 성취기준·선수관계·
세부 학습 주제는 한국 교육과정 학습맵 MCP 2종에서 가져오고, 수업 자료는 기본으로
**웹 문서(HTML)·텍스트(TXT)·마크다운(MD)**으로, 선택하면 편집 가능한 **한글(HWPX) 문서**로도
나옵니다.

> 이 플러그인은 **사회·역사 전용**입니다 — 초3–6 사회·중학교 사회·중학교 **역사**·고교
> 통합사회1·2·**한국사1·2**·**사회 선택과목 12종**(경제·법과 사회 등)·**역사 선택과목 3종**
> (세계사·동아시아 역사 기행·역사로 탐구하는 현대 세계)을 다룹니다.
> 도덕과(윤리 계열)·초1–2는 범위 밖입니다.

## 무엇을 만드나

스킬 2종이 들어 있습니다.

**① 수업 설계** — "중2 사회, 인권 보장과 헌법 45분 수업 만들어 줘"라고 하면 한 턴에 세 가지가
나옵니다.

| 문서 | 내용 |
|---|---|
| 수업안 | 성취기준 원문, 범주별 학습 목표(지식·이해 / 과정·기능 / 가치·태도), 단원 탐구 질문과 이번 차시의 탐구 질문, 자료 카드(사료·통계·지도 등 출처 표시), 단계별 전개와 분 배분, 예상되는 학생 생각, 설계 노트 |
| 학생 자료 | 학생이 직접 쓰는 학습지 — 자료를 읽고 근거를 짚어 답하는 과제, 답란 |
| 관찰 템플릿 | 순회하며 볼 것(look-for), 정리 문항 분류 기준, 기록표 |

논쟁적 쟁점(정치·이념 관련)을 다루는 차시는 교실에서도 논쟁적으로 유지합니다 — 특정 입장을
정답으로 제시하지 않고, 실재 정당·정치인을 명명하지 않으며, 가치 판단 문항은 "근거를 들어
자신의 입장을" 형식으로 냅니다(교육기본법 제6조 교육의 중립성).

역사 계열(중학교 역사·한국사1·2·역사 선택과목 3종)에서는 자료 카드가 **사료** 형태로 나오고, 사료마다 출처
(누가·언제·왜 만들었나)를 먼저 확인하게 합니다. 평가가 갈리는 인물·사건은 하나의 해석을
정답으로 제시하지 않고 복수 해석을 같은 무게로 병기하며, 학습맵이나 실측 자료로 확인되지
않는 서술은 교사용 문서에는 그 자리에 "확인 필요"를 표시하고, 학생 지면에는 아예 싣지
않습니다.

**② 수준별 차별화** — "우리 반은 편차가 커요"처럼 기존 수업이 있을 때, 교사용 차별화
수업안 1종 + 학생용 수준별 학습지 3종(가·나·다 모둠)을 만듭니다. 세 수준은 **같은 자료,
같은 핵심 탐구 질문**을 다루고 지원만 달라집니다 — 기초 수준이라고 탐구를 빼지 않습니다.

각 패키지의 문서들은 하나의 소스에서 렌더되므로 서로 어긋날 수 없습니다. 성취기준은
학습맵이 준 **공식 원문 그대로** 인용하며, 바꿔 쓰지 않습니다.

## 설치

Claude Code에서 두 줄이면 됩니다.

```
/plugin marketplace add newskool4d-sketch/social-teacher-skills
/plugin install social-teacher-skills@social-teacher-skills
```

터미널에서 하려면 같은 인자로 `claude plugin marketplace add …` / `claude plugin install …`을
쓰면 됩니다. 설치 후 Claude Code를 재시작하면 스킬 2종(`ko12-lesson-planning`,
`ko12-lesson-differentiation`)과 학습맵 MCP 2종이 함께 올라옵니다.

저장소를 clone해서 쓰려면 clone한 폴더의 경로를 `marketplace add`에 그대로 넘깁니다.

학습맵 MCP 2종은 `plugin/.mcp.json`에 번들되어 있어 `npx`로 자동 실행됩니다 — 이를 위해
**Node.js(`npx` 포함)**가 필요합니다. Node.js가 없으면 학습맵 없이 동작하고 수업안에 미연결
안내가 붙습니다. 문서 렌더에는 Python 3만 있으면 됩니다 — 추가 패키지 없이 표준
라이브러리만 씁니다.

## 사용

```
중2 사회, 인권 보장과 헌법 45분 수업 만들어 줘
```

```
중3 역사, 근현대 단원 45분 수업 만들어 줘
```

```
이 수업을 우리 반 수준에 맞게 세 단계로 나눠 줘
```

학년·주제만 있으면 됩니다. 성취기준 코드(`[9사(일사)01-01]`)를 알고 있으면 그대로 써도
됩니다. 학습맵이 연결되지 않은 상태에서도 동작하며, 그 경우 수업안에 안내 문구가 붙습니다.

### 출력 형식

| 형식 | 기본 | 비고 |
|---|---|---|
| HTML·TXT·MD | ✅ | 요청한 형식만 고를 수 있음 ("마크다운으로만 주세요") |
| HWPX(한글) | 선택 | "한글 파일로도 주세요"처럼 요청할 때 생성 |

HWPX는 내장 렌더러(표준 라이브러리로 OWPML 직접 생성)가 만든 뒤, **이 컴퓨터에 설치된
한글이 열어 다시 저장**합니다 — 한글이 기본 출력 엔진입니다. 한글이 없거나(Mac·Linux)
자동화가 실패하면 내장 렌더러 파일을 그대로 씁니다. 한글 호출은 Windows 기본 PowerShell로
하므로 추가 패키지가 없습니다. 한글 보안 승인 창 없이 쓰려면 한컴 자동화 보안 모듈
(`FilePathCheckerModule`)을 등록해 두세요. 엔진은 환경변수 `HWPX_ENGINE`
(`auto` 기본 · `hancom` 한글 필수 · `python` 내장만)으로 바꿀 수 있습니다.

단원 제목이 섞이는 실제 절취 결함이 있는 소수 레코드에만 공식 고시문과 대조하라는 안내가
함께 인쇄됩니다.

이 플러그인은 검정 교과서의 활동·지문·삽화·문항을 재현하지 않습니다. 교사가 출판사를
확언하지 않으면 출판사명을 산출물이나 대화 어디에도 쓰지 않습니다. 신문 기사·방송·교과서
지문처럼 저작권이 있는 자료는 학생 자료에 발췌를 싣지 않고 출처만 지목합니다 — 법령·조례·
정부 간행물·공공데이터·저작권 만료 사료만 발췌를 실을 수 있습니다.

## 원저작 표기

이 저장소는 두 겹의 이식 계보를 가집니다.

1. 원본은 Anthropic, PBC와 Learning Commons의 `k12-teacher-skills` v0.6.0이며 Apache-2.0으로
   배포됩니다.
2. 이 저장소는 그 한국어 과학판인 [`science-teacher-skills`](https://github.com/raphysicst-create/science-teacher-skills)
   v0.3.0-preview.1(Apache-2.0)을 포크해 **사회과로 전면 대체**했습니다.

이 저장소도 Apache-2.0을 따르며, 파생 파일에 SPDX 헤더와 원본 경로를 남겼습니다. 자세한
내용은 [LICENSE](LICENSE)와 [NOTICE](NOTICE)를 보세요.

과학판에서 바꾼 지점은 넷입니다 — 과목 pedagogy(3범주 + 자료 기반 탐구), 범위 확장(고교
**통합사회1·2**까지), 논쟁 문제 가드레일 신설(교육기본법 제6조), 자료(source) 규칙
신설. 렌더러·산출 스키마·오케스트레이터 구조는 과학판과 같아 원본
Anthropic k12-teacher-skills까지 추적됩니다.
